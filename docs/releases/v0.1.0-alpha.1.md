# Eterra Alpha Runtime `v0.1.0-alpha.1`

This component release prepares the Alpha runtime upgrade from spec 103 to 104. The canonical coordinated release packet is maintained in the eterra.online repository under `docs/releases/v0.1.0-alpha.1/`.

## Runtime behavior

- Gamer tag writes retain chain-authoritative first-set/update behavior and AlphaAccess enforcement.
- ArcadeCore includes the Nova Rail configuration needed by fresh chains.
- Existing Alpha state is preserved. Genesis changes do not change a running database.
- Nova Rail live configuration is seeded only through the explicit, idempotent operator action.

## Release rules

- Never use `--purge-state`, `--fresh`, or reset scripts for this release.
- Build the hash-locked bundle with `scripts/release/build-runtime-upgrade-bundle.sh`.
- Rehearse on a copied Alpha snapshot with `scripts/release/rehearse-runtime-upgrade.sh`.
- Submit `Sudo.sudo(System.set_code)` only through `Eterra.Chain.Operator`, after the separately authorized live checkpoint.
- Verify spec/code hash, production, balances, Gamer/ArcadeCore reads, faucets, and authorities before enabling enforced AlphaAccess.

No tag or live upgrade is created by these scripts.
